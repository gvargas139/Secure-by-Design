# Glosario

| Término | Significado |
|---|---|
| Activo | Recurso de valor para la organización |
| Amenaza | Evento capaz de causar daño |
| Vulnerabilidad | Debilidad susceptible de explotación |
| Riesgo | Posibilidad e impacto de una pérdida |
| CIA | Confidencialidad, integridad, disponibilidad |
| SGSI | Sistema de Gestión de Seguridad de la Información |
| CISO | Responsable ejecutivo de seguridad de información |
| DREAD | Modelo de valoración de amenazas |
| CVE | Identificador de vulnerabilidad conocida |
| Hardening | Fortalecimiento de configuración y operación |
| OWASP | Comunidad y proyectos de seguridad de aplicaciones |
| ASVS | Estándar de requisitos de verificación de seguridad |
| SDLC | Ciclo de vida del desarrollo de software |
| MFA | Autenticación con múltiples factores |
| SSO | Inicio de sesión único |
| TLS | Protocolo de protección de comunicaciones |
| ORM | Mapeo objeto-relacional |
| XSS | Cross-Site Scripting |
| XXE | Entidades externas XML |
| CSP | Política de seguridad de contenidos |
| SAST | Análisis estático de seguridad de aplicaciones |
| Log | Registro de eventos |
| DDoS | Denegación de servicio distribuida |

Consulta los resúmenes de [[Resumen semana 5]], [[Resumen semana 6]] y [[Resumen semana 7]] para profundizar.
