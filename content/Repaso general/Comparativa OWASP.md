# Comparativa OWASP 2017 y 2021

> [!warning] Aclaración del material
> Los apuntes S6 y S7 mezclan números de categorías. Esta tabla distingue las versiones para evitar memorizar encabezados incorrectos. Se mantiene 2021 como referencia del ramo, no como afirmación de que sea la edición más reciente.

| Tema | 2017 | 2021 |
|---|---|---|
| Control de acceso | A5 | A01 |
| Fallos criptográficos / exposición de datos | A3 | A02 |
| Inyección | A1 | A03 |
| XSS | A7 | A03 (integrada) |
| Diseño inseguro | — | A04 |
| Configuración incorrecta | A6 | A05 |
| XXE | A4 | A05 (integrada) |
| Componentes vulnerables | A9 | A06 |
| Autenticación | A2 | A07 |
| Deserialización insegura | A8 | A08 (integrada) |
| Registro y monitoreo | A10 | A09 |
| SSRF | — | A10 |

Las categorías agrupan riesgos y pueden cambiar de alcance entre versiones. No equivalen a una certificación ni a una lista exhaustiva de controles.

Referencias de contraste: [OWASP 2017](https://owasp.org/www-project-top-ten/2017/) y [OWASP 2021](https://owasp.org/Top10/2021/).
