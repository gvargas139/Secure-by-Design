# Amenazas y actores

Una ruta de ataque conecta un actor, un vector, una debilidad y un impacto. El riesgo depende del contexto y no todos los caminos tienen la misma gravedad.

| Amenaza | Descripción |
|---|---|
| Ataques de contraseña | Intentos de obtener o adivinar credenciales |
| DDoS | Sobrecarga distribuida de un servicio, a veces mediante botnets |
| SQL injection | Datos interpretados como instrucciones SQL |
| XSS | Contenido no confiable ejecutado como código en el navegador |

| Actor descrito por el apunte | Característica |
|---|---|
| Script kiddie | Usa herramientas creadas por terceros con poca experiencia |
| Hacktivista | Motivación política o social |
| Usuario descuidado | Puede ocasionar daño accidental |
| Ciberdelincuente | Busca acceso ilícito, lucro u otros objetivos |
| APT | Amenaza dirigida, persistente y con capacidades avanzadas |

El término hacker no equivale necesariamente a delincuente: también existe investigación autorizada de seguridad.

Fuente: S7, pp. 7–11. Aclaración terminológica propia.
